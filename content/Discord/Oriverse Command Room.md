# Briefing

The `command_room` channel is a secret channel within [[The Oriverse]] discord server. 

> [!info]- Method of Access
> As explained in [[Oriverse Basement|The Basement]]:
> 
>  ![[Oriverse Basement#!press-the-button|The Basement]]

It is used to post various updates regarding [[Oriverse Basement|The Basement]], the [[Short Stories]] and the Oriverse discord server itself. It also posts notifications over every person that manages to unveil it, and disallows any normal member from sending messages

# Clues

## Command Terminal

The first few messages in the channel explain what the command room is:

* Oridont's message explains:
  > Welcome to the Control Room, please be mindful of what you touch, this room is extremely sensitive
* Furthermore, a message from [[Smexybot]] explains:
  > There's a handful of documents scattered about the room, though ultimately sparse in comparison to complex console that glares down at you.

As such, paired with information acquired from [[Oriverse Basement|The Basement]] it is assumed that the Control Room is a room with a big terminal, with other documents scattered about
