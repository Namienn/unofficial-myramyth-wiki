# Briefing

The Channel `the_basement` within [[The Oriverse]] is ran by commands in order to uncover clues hiding under cryptic sentences

# Clues

## Commands

Scattered throughout the many quotes of the basement, there are a few that prompt the user to do (or not do) something, which in turn allows access to further clues hidden within the server

### !next-room

One of the two main commands of the channel, sending a random message related to different "rooms" within the basement
### !escape

One of the two main commands of the channel, sending a random message related to different attempts at "escaping" the basement
### !press-the-button

The `!press-the-button` command is discovered through the following quotes:

Through !escape:
> Oh, \<user>, that's not an escape, that's the control room! (Don't press the button)

Through !next-room
> \<user> seems to have stumbled across the control room... There a lot of buttons, but only one big one that says **DO NOT PRESS**.

it hints at the fact you can press the big button on the control room, therefore obtaining access to the [[Oriverse Command Room]] channel after the following confirmation that the command worked:

> It seems that the Basement has changed in some way...

### !Notes

A discontinued command that would either grant you access to a dedicated discord channel or randomly pump out hints and pieces of lore.

It is referenced in the quote:
>!Well !\<user>, !there's !nothing !useful !in !this !room, !just !a !stack !of !useless !Notes.
